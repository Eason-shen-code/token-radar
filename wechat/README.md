# 微信分享入口

三个文件，用途不同：

| 文件 | 用途 |
|---|---|
| `分享卡.png` | 1080×1440，直接发微信或朋友圈。二维码已通过解码校验，扫出来的链接与分享链接完全一致 |
| `二维码.png` | 1000×1000 纯二维码，白底，适合贴到文档、PPT、海报里 |
| `index.html` | H5 入口页，单文件 17KB，二维码内联成 base64，无外部依赖 |

## 为什么用二维码而不是直接发链接

托管平台要求每个请求都带 `?sharecode=`，转发时这个参数经常被截掉，截掉就是 403「链接不完整」。二维码把完整 URL 编进去了，扫码/长按识别不会丢参数。

## H5 入口页怎么用

`index.html` 是单文件，扔到任何能托管静态页的地方就能访问：

- 公司内网 / 对象存储 / Nginx
- GitHub Pages
- 任意静态托管

页面自己不需要任何参数，因为它把带参链接写死在里面了。

## 重新生成

URL 变了就改这三个脚本里的 `URL` 常量再跑：

```bash
npm i qrcode jsqr pngjs @napi-rs/canvas
node gen.cjs      # 生成 二维码.png
node verify.cjs   # 解码校验，必须输出「一致」
node card.cjs     # 合成 分享卡.png
```
